# HTTP API — 返回值（业务码）汇总

本文档结合 `docs/http_api_design.md`（设计规范）和目前实现文件 `src/robot_http_server.cc`，列出：
- 设计规范中的业务错误码（权威参考）
- 实现中当前使用的 `code` 值（来自 `sendJson` 调用）
- 不匹配项与建议映射（把实现中的短码/HTTP 语义码映射到设计中的四位业务码）

注意：业务级错误码按模块划分（`0` 表示成功，`1xxx` 参数错误，`2xxx` 运动/规划错误，`3xxx` 机器人状态错误，`4xxx` 标定错误，`5xxx` 异步任务错误，`-6xxx` Lua 脚本错误）。

---

**一、设计规范（摘录）**

- `0` — 成功

请求参数类（1xxx）示例：
- `1001` JSON 格式错误或缺少必填字段
- `1002` 关节 ID 超出范围
- `1003` 关节数据长度与机器人关节数不匹配
- `1004` 位姿数据格式错误
- `1005` 速度/加速度参数超出安全范围
- `1006` 不支持的工作模式

运动规划类（2xxx）示例：
- `2001` IK 无解
- `2002` 超出关节限位
- `2003` 超出工作空间
- `2004` 运动轨迹规划失败
- `2005` 圆弧三点共线

机器人状态类（3xxx）示例：
- `3001` 未使能
- `3002` 机器人处于故障状态
- `3003` 正在执行其他运动指令
- `3004` 运动线程启动失败
- `3005` 工作模式不匹配

标定类（4xxx）示例：
- `4001` 标定点数据不足
- `4002` 标定计算失败（数值异常）
- `4003` 标定误差过大
- `4004` 无效的坐标系类型

异步任务类（5xxx）示例：
- `5001` 任务 ID 不存在
- `5002` 异步任务执行超时

Lua 脚本类（-6xxx）：
- `-6001` 脚本状态冲突
- `-6002` Lua 编译或运行错误
- `-6003` 无效断点
- `-6004` 脚本文件不可用
- `-6005` 脚本已停止

---

**二、实现中当前使用的 `code`（来自 `src/robot_http_server.cc`）**

通过扫描 `sendJson(...)` 调用，发现实现中使用的 `code` 列表（去重）：

- `0`  — 成功
- `400` — 多处用于参数/JSON 错误（HTTP 语义）
- `404` — mesh 未找到 / 路由错误（HTTP 语义）
- `500` — 内部错误（URDF 解析失败、设置工作模式失败、标定失败等，HTTP 语义）
- `501` — MovePath 未实现（HTTP 501 用法）
- `2001` — IK 无解（符合设计）
- `2004` — 运动失败（符合设计中“规划失败”类别）
- `3003` — 同步等待超时（实现里用来表示 motion timeout）
- `5001` — 异步任务不存在（符合设计）

（注：代码库中也有我已改过的 `1001` 在少数位置；但大部分实现仍然使用短码 HTTP 语义。）

---

**三、不匹配项 & 建议映射**

下面列出实现中不符合设计文档的返回码（即使用 HTTP 状态语义或非 4 位业务码），并给出建议替换的设计文档业务码：

| 实现 code | 出现位置（函数/意图） | 建议替换为（设计码） | 说明 |
|---:|---|---:|---|
| 400 | 参数校验/JSON 解析失败（大量函数，如 `handleMoveJ`, `handleMoveL`, 单轴/多轴接口等） | 1001 | 设计：`1001` 表示 JSON 格式错误或缺少必填字段，适用于大多数 400 场景。
| 404 | `handleGetLinkMesh`（mesh 文件未找到） / 路由未命中 | 1001 或 2003 视语义而定；推荐 `1001` | 设计中 404 是 HTTP 状态，业务层使用 4 位码。mesh 文件未找到可视为资源参数错误，映射到 `1001`。
| 500 | URDF 解析失败、设置工作模式失败、标定失败等（多个位置） | 对应分类替换：设置工作模式失败 -> `3002`（机器人状态类）；URDF 解析失败/资源类 -> `1001`（参数/资源）; 标定失败 -> `4002` | `500` 为 HTTP 内部错误，需根据语义替换为具体业务码。
| 501 | `handleMovePath` 未实现 | 2004 或保留 2004（规划失败） | 设计没有 501，未实现应返回“功能/规划失败”的 2xxx 类（或专门的未实现码）。建议使用 `2004` 并在 message 中标注 "not implemented"。
| 3003 | 同步等待超时（motion timeout） | 5002（异步任务超时） 或 新增 `3004` 视上下文 | 设计中 `3003` 表示“正在执行其他运动指令”，不等同于超时；同步超时建议归入异步/任务超时类 `5002`。

---

**四、当前实现 vs 设计：差异摘要**

- 设计：业务码必须为 4 位数字并按模块划分（1xxx/2xxx/...）。
- 实现：大量位置仍然返回 HTTP 风格短码（400/404/500/501），会导致上层无法统一按业务码进行自动化恢复策略判断。
- 为兼容性与规范性，建议将实现中所有 `sendJson(..., <short-code>, ...)` 替换为设计文档四位码，并保证 `success` 字段为 `false` 时填充正确的 `code`（非 HTTP 状态码）。
